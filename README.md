## 💻 Run Locally

You can run the portfolio on your computer without installing a frontend framework.

### 1. Clone the repository

```bash
git clone https://github.com/Saravanan-mc/portfolio.git
```

### 2. Open the project folder

```bash
cd portfolio
```

### 3. Launch the website

Open `index.html` in your web browser.

Alternatively, open the folder in Visual Studio Code and use the Live Server extension for local development.

## 🔧 Customization

You can customize the portfolio by editing the following files:

- **`index.html`** — Update your introduction, skills, project information, and page content.
- **`styles.css`** — Change colors, typography, spacing, layouts, and responsive styles.
- **`script.js`** — Modify interactive behavior and website functionality.
- **`assets/`** — Add profile images, project screenshots, icons, and other media.
- **`.github/workflows/`** — Review the automated deployment configuration.

## 🚀 Deployment with GitHub Pages

This repository includes a GitHub Actions workflow for static-site deployment.

To publish updates:

1. Make your changes locally or directly on GitHub.
2. Commit and push the changes to the `main` branch.
3. Open the repository's **Actions** tab to check the workflow.
4. Wait for the deployment to complete.
5. Visit your published portfolio website.

GitHub Pages settings and the workflow configuration must be set up correctly for deployment to succeed.
